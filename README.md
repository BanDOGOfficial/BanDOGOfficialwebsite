# BanDOG website

Static website for BanDOG (BDOG), designed for free hosting such as GitHub Pages.

Files:
- index.html — main website
- bandog-icon.png — BanDOG token icon

Before publishing:
1. Create the official X, Telegram and Discord accounts.
2. Replace the placeholder community links in index.html.
3. After the token contract is deployed, add the contract address and explorer link.
4. Review the site's legal/disclaimer text for your jurisdiction.

The site uses no paid libraries, hosting, or external assets.
